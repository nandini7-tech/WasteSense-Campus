## What is inside this zip?
- `index.html`: main interactive prototype
- `docs/Project-Brief.md`: project description for PPT/PDF submission
- `docs/Responsible-AI.md`: mandatory responsible AI section
- `docs/Impact-Statement.md`: expected impact and beneficiaries
- `docs/Prompt-Workflow.md`: AI workflow and prompt/RAG design
- `docs/Demo-Script.md`: 3-minute presentation/demo script
- `docs/Slide-Outline.md`: suggested PPT slide structure
- `docs/Checklist.md`: submission checklist
- `docs/Notes-for-Student.md`: important customization notes

## How to run the prototype
1. Extract the zip.
2. Open `index.html` in any modern browser.
3. No server, npm install, or backend is required.

## How to submit
1. Replace all bracketed placeholders with your real name, college, and local observations.
2. Open `index.html`.
3. Use the **Print / PDF** button to create a PDF version if needed.
4. Use `docs/Slide-Outline.md` to prepare your PPT.
5. Keep the Responsible AI section visible in your final submission.

## Important
This prototype is intentionally offline and simulated. For a real deployment, connect the classification and policy Q&A modules to an approved AI stack such as IBM Granite models, IBM BOB, or a campus-hosted RAG pipeline using official waste-management documents.
